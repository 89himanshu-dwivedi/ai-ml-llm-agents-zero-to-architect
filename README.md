# AI / ML / LLM / Agents: Zero to Architect

Hi, I'm **Himanshu Kumar** — Technical Lead & Solution Architect, **8 years** in enterprise engineering, now building AI systems.

I work at **CRISIL Ltd, an S&P Global company**, on S&P Global projects.

This repo is my open log of the AI path: from maths and classical ML through to LLMs, agents, and designing AI systems that survive production.

---

## What you'll get from here

- Foundations done properly — Python, NumPy, pandas, linear algebra, probability, statistics
- Classical ML with honest evaluation, not just `.fit()` and a happy accuracy number
- Deep learning fundamentals: backprop, CNNs, transformers, PyTorch
- LLM engineering: prompting, chunking, embeddings, vector stores, hybrid retrieval, reranking
- Agents: tool calling, planning, memory, multi-agent patterns, MCP, guardrails
- LLMOps: eval harnesses, tracing, cost and latency budgets, caching, safety
- Architecture write-ups — model selection, data flow, privacy, deployment topology

My rule here: **nothing gets a demo until it has an evaluation**, and anything calling an LLM gets its cost and latency tracked.

Useful if you're an experienced engineer moving into AI and you want the engineering side, not just notebook tutorials.

## How this repo is built

I add one folder at a time as I work through a topic. Each folder holds my notes plus runnable code.
