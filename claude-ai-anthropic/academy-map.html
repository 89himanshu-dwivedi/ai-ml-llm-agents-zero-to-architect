How to use this page This course is not a replacement for Claude Academy - it is the engineering-depth companion. Academy gives you the official curriculum, videos, quizzes and completion badges. This site gives you the failure modes, the cost maths, the architecture trade-offs and the interview answers. Where a row says "go to the source", that content is genuinely better taken there.

Why the cloud editions are 65 lessons and this course gives them one module Because roughly 90% of those courses is the same material as the direct-API course, re-recorded with a different client and model ID. Learn the patterns once, then learn the deltas - auth, regions, model identifiers, feature parity. That is module 23.
