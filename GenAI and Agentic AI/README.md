# GenAI & Agentic AI: Zero to AI Architect

Hi, I'm **Himanshu Kumar** — Technical Lead & Solution Architect with **8 years of experience** in enterprise engineering, now expanding into **GenAI and Agentic AI Engineering**.

I work at **CRISIL Ltd, an S&P Global company**, on S&P Global projects.

This repository is my open learning log as I explore the journey from LLM fundamentals to **Agentic AI Engineering and AI System Architecture**.

The goal is to build a strong foundation in AI through detailed technical explanations, video-based learning, practical coding, and structured Markdown documentation.

---

## What You'll Get From Here

- **Generative AI Fundamentals** — Understand GenAI concepts, architectures, capabilities, and practical applications.
- **LLMs & Prompt Engineering** — Explore large language models, prompt design, and effective LLM interactions.
- **LLM API Integration** — Connect language models with applications and build AI-powered functionality.
- **RAG Engineering** — Understand retrieval, knowledge integration, and context-aware AI applications.
- **Conversational Memory** — Explore chatbot memory, conversation history, and context management.
- **AI Agent Engineering** — Build agents using LangChain and understand tool calling, agent workflows, and decision-making patterns.
- **Multi-Agent Systems** — Explore AutoGen and collaboration between AI agents.
- **AI Workflow Automation** — Build automation workflows using n8n and integrate AI capabilities into business processes.
- **Model Context Protocol (MCP)** — Understand MCP architecture, tool connectivity, and external context integration.
- **Multi-Tool AI Agents** — Explore practical implementations of agents that interact with multiple tools.
- **Practical AI Development** — Learn through detailed video explanations, live coding, implementation examples, and project-oriented learning.

My approach is to go beyond simply using AI frameworks. I want to understand the architecture, implementation patterns, integrations, and engineering considerations behind AI-powered systems.

## How This Repository Is Built

I organize the learning journey module by module, converting the video lessons into detailed Markdown reference files.

Each module may include:

- **Video References** — Links to the original video lessons for the corresponding topic.
- **Detailed Markdown Notes** — Structured documentation created from video explanations and technical discussions.
- **Conceptual Understanding** — In-depth explanations of concepts, terminology, and underlying principles.
- **Live Coding Notes** — Code walkthroughs, implementation details, and practical examples covered in the lessons.
- **Architecture Explanations** — Diagrams and technical breakdowns wherever useful.
- **Code Implementations** — Experiments and runnable examples developed while learning.
- **Key Takeaways** — Important concepts, implementation patterns, and technical insights.

The video lessons serve as the learning source, while the Markdown files act as detailed, searchable technical references that I can revisit, improve, and expand over time.
